# GitHub Upload Checklist

1. Create a new GitHub repository named:
   `EMG-Lower-Limb-Movement-Classification`

2. Upload:
   - `README.md`
   - `requirements.txt`
   - `.gitignore`
   - `EMG_Lower_Limb_Movement_Classification.ipynb`
   - `final_emg_random_forest.pkl`
   - `emg_feature_names.pkl`
   - `report/EMG_Lower_Limb_Movement_Classification_Report.docx`

3. Add the confusion-matrix and feature-importance images if you saved them.

4. Do NOT upload the original dataset unless its license explicitly permits redistribution.

5. If a model/data file is too large for normal Git, use Git LFS rather than forcing it into regular Git history.
